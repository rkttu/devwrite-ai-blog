# 예약 발행 기능 철회

- 결정일: 2026년 8월 22일
- 상태: 적용

## 도입 배경

초기 구현은 포스트의 `date`에 미래 시각을 입력하고 GitHub Actions cron이 Hugo를 다시 빌드하도록 구성했습니다. Hugo는 빌드 시각보다 미래에 있는 포스트를 산출물에서 제외합니다.

## 확인한 한계

GitHub Actions cron은 지정한 시각에 작업을 시작한다고 보장하지 않습니다. 러너 대기열과 서비스 상황에 따라 실제 발행 시각이 늦어질 수 있습니다.

또한 이 블로그는 공개 Git 저장소와 정적 파일로 운영됩니다. Hugo가 미래 포스트를 사이트 목록과 산출물에서 제외하더라도 서버 인증이나 비공개 콘텐츠 저장소 역할을 제공하지 않습니다. 따라서 예약 시각 전 콘텐츠 보호까지 기대하기 어렵습니다.

## 결정

예약 발행 기능과 정기 cron 배포를 제거합니다. 모든 포스트의 `date`는 현재 시각이나 과거 시각만 허용합니다. 글은 세 언어의 `draft`를 `false`로 변경한 커밋을 `main`에 반영할 때 발행합니다.

정확한 예약 시각과 발행 전 접근 제어가 필요해지면 해당 기능을 제공하는 콘텐츠 관리 시스템이나 게시 플랫폼을 별도로 검토합니다.

## 결과

- GitHub Actions 정기 실행 제거
- 미래 날짜 포스트에 대한 검증 실패
- 테마의 예약 상태 표시 제거
