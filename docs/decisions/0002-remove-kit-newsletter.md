# Kit 뉴스레터 연동 제거

- 결정일: 2026년 8월 22일
- 상태: 적용

## 배경

이 저장소는 Kit 구독 폼과 API 기반 브로드캐스트 생성 스크립트를 포함했습니다. 배포 후 새 글을 감지해 브로드캐스트 초안을 만드는 GitHub Actions job도 운영했습니다.

## 결정

현재 뉴스레터를 사용하지 않으므로 Kit 연동 전체를 제거합니다. 사이트는 언어별 RSS 피드를 구독 수단으로 유지합니다.

## 제거 범위

- Kit 구독 폼과 외부 스크립트
- 자동 브로드캐스트 job
- 수동 브로드캐스트 워크플로
- Kit API 호출과 발행 글 감지 스크립트
- 연동 전용 테스트

뉴스레터를 다시 도입할 때는 사용할 서비스와 발행 흐름을 새로 결정하고 별도 기능으로 구현합니다.
