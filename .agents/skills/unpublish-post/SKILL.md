# 게시 대상 제외

대상 slug의 한국어, 영어, 일본어 파일을 확인하고 정확한 경로를 사용자에게 알립니다. 세 언어의 `draft` 값만 `true`로 바꾸며 본문과 다른 메타데이터는 수정하지 않습니다.

정적 사이트의 `draft` 설정은 접근 제어나 비공개 보호 기능이 아닙니다. Git 기록, 이전 배포물, CDN 또는 검색 엔진 캐시에 콘텐츠가 남을 수 있다고 알립니다.

변경 후 `python3 scripts/validate_translations.py`를 실행합니다. 로컬 상태 변경만 요청받았다면 여기서 중단합니다.

운영 사이트에서도 내려 달라는 요청을 받은 경우에는 커밋과 푸시의 외부 영향을 알리고 승인을 확인한 뒤 `$deploy-blog-post`를 사용합니다. 배포 후 세 언어 URL이 404를 반환하는지 제한된 횟수로 확인합니다. 캐시와 검색 엔진 사본까지 삭제되었다고 단정하지 않습니다.
