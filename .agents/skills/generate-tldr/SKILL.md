# Description과 TLDR 작성

대상 글 전체를 읽고 이미 검증된 핵심 주장, 대상 독자, 실용적인 결과를 추출합니다. 한국어 값을 작성하거나 교정하기 전에 `writing-style-guide.md` 전체를 읽고 한두 문장의 산출물에 해당하는 규칙을 적용합니다. 본문에 없는 수치, 성과, 경험을 만들지 않습니다.

`description`은 검색과 Open Graph에 사용할 한 문장으로 작성합니다. 한국어는 50자에서 160자를 기준으로 삼고 영어와 일본어는 자연스러운 한 문장 길이를 우선합니다.

`tldr`은 독자가 본문을 읽기 전에 범위와 결론을 파악할 수 있는 한두 문장으로 작성합니다. 목차를 나열하지 않고 `description`과 다른 문장을 사용합니다.

영어와 일본어 값은 각 언어의 자연스러운 기술 문체로 작성합니다. 여러 번역본을 함께 수정한다면 의미는 같게 유지하되 직역하지 않습니다.

사용자가 값만 요청하면 후보를 보여 주고 파일을 수정하지 않습니다. front matter 갱신까지 요청하면 대상 파일만 수정한 뒤 세 언어의 불변 필드가 달라지지 않았는지 확인합니다.
