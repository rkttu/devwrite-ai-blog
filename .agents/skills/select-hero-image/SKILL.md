# 히어로 이미지 선정

글의 제목, 핵심 주장, 분위기를 읽고 과도하게 문자 그대로 표현하지 않는 가로형 이미지를 찾습니다. 최소 1200×630 픽셀과 1.91:1에 가까운 비율을 기준으로 삼습니다.

외부 이미지는 검색 결과의 썸네일 URL을 원본으로 사용하지 않습니다. 원본 페이지에서 다운로드 권한과 저작자 표시 조건을 확인하고 출처 링크를 기록합니다. 사용 조건을 확인하지 못하면 다운로드하지 않습니다. 생성 이미지를 요청받으면 사용 가능한 이미지 생성 도구를 사용하고 결과를 먼저 검토합니다.

후보를 요청받았다면 이미지, 출처, 라이선스 또는 사용 조건, 추천 이유를 보여 주고 파일을 변경하지 않습니다. 다운로드와 적용까지 요청받았다면 `assets/images/posts/<slug>.<확장자>`에 저장하고 언어별 `cover.image`, `cover.alt`, 필요한 `cover.caption`을 갱신합니다.

저장 후 현재 운영체제에 맞는 이미지 최적화 스크립트를 실행합니다.

```bash
python3 scripts/optimize_images.py --slug "<slug>" --delete-originals --update-frontmatter
python3 scripts/check_asset_sizes.py
```

원본 삭제 옵션을 사용하기 전에 대상 파일을 정확히 확인합니다. 글과 무관한 이미지나 기존 사용자 파일을 삭제하지 않습니다.
